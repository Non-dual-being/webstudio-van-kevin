# Kevin Webstudio

Commerciële portfolio- en bedrijfswebsite voor Kevin Webstudio.

## Stack

- PHP 8.4
- Laravel 13
- Inertia 3
- Vue 3
- TypeScript
- Tailwind CSS
- Vite
- SQLite voor lokale ontwikkeling
- Pest
- pnpm

## Lokale ontwikkeling

```bash
use-php84
composer install
pnpm install
php artisan migrate
php artisan serve
```
